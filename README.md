# schoolAlarm

학교 급식정보를 조회하는 반응형 정적 웹사이트입니다. (HTML/CSS/JavaScript만 사용)

## 실행 방법
- `index.html`을 더블클릭해서 브라우저로 열면 됩니다.
- 또는 VS Code / Cursor의 Live Server 확장으로 실행해도 됩니다.

## 사용 방법
- 상단의 **학교명**을 검색 → 목록에서 **선택**
- **날짜**를 고르고 **급식 조회**
- 결과가 없으면 주말/방학/학교 일정 등의 이유일 수 있습니다.

## 파일
- `index.html`: 화면
- `styles.css`: 반응형 스타일
- `app.js`: NEIS Open API 호출 및 렌더링
